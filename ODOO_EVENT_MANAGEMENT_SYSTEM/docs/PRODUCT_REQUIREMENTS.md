# Product Requirements — EMS Odoo 19 Community

## Functional domains

- Events, venues and access zones
- Registrations and secure ticket issuance
- Ticket transfer/revoke/rotation
- Badge issuance and zone authorization
- Scanner device enrollment/revocation
- Online and offline check-in synchronization
- Waitlist and promotion
- Reserved seating and temporary seat holds
- Notification queue
- Website/portal ticket experience
- Mobile/scanner API
- Stripe/Odoo payment linkage
- Operational reporting
- GDPR export/anonymization workflow
- Optional AI assistance

## Enterprise constraints

- Multi-company aware
- Organizer-scoped record rules
- Auditability
- No card data storage
- No secrets in Git
- Idempotent scan and payment operations
- Upgrade-safe addons
- Odoo 19 Community only
